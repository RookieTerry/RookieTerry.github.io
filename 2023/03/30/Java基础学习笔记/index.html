1.compareTo方法

compareTo 方法用于将 Number 对象与方法的参数进行比较。可用于比较 Byte, Long, Integer等。

该方法用于两个相同数据类型的比较，两个不同类型的数据不能用此方法来比较。

  • 如果指定的数小于参数返回 -1。

静态

在Java语言中，我们使用static关键字来表示静态。静态方法、静态属性会在编译前在内存中加载，所以静态方法中无法直接调用非静态方法。静态属性只能通过类名.静态属性名的方式调用，而静态方法可以直接在静态方法中调用，或者用类名.静态方法名的方式调用。非静态方法只能通过对象.方法名调用。

this和super关键字

this关键字表示对象内对类的当前实例的引用，它只能在实例的上下文中使用。

super关键字用于引用直接父类对象，访问父类的构造方法、普通方法和属性。引用父类构造器时是super()，引用父类方法时是super.方法名()，括号里传递的是父类方法中的实参。

需要注意的是，this和super都要放在方法内的第一行，所以两者只能选一个。

final关键字

相当于C++中的const关键字，表示常量，可用来修饰类、方法和变量。修饰类时，表示这个类不能被继承；修饰方法时，表示这个方法不能被重写；修饰变量时，如果是基本数据类型的变量，则其数值一旦在初始化之后便不能更改；如果是引用类型的变量，则在对其初始化之后便不能再让其指向另一个对象。

非静态代码块：在new对象时加载进内存。

在调用属性或方法时，属性看父类，方法看子类。例如Animal和Dog两个类均含有属性id和方法call()，则a.id调用的是Animal类的id属性，a.call()调用的是Dog类的call()方法。

当类型发生强制转换时，只能是父类的对象强制转换成子类的，相同级别的类不能转换。例如，Dog d = (Dog) a是合法的，而Cat c = (Cat) a会报错。

使用关键字instanceof可以判断一个对象是否是一个类（或接口、抽象类、父类）的实例。例如：a instanceof Animal。

异常处理

异常可分为两种类型：运行时异常和非运行时异常。捕获异常可以让程序在遇到错误时能够继续执行，而不是报错并中断执行。程序每次只会抛出一种异常。
